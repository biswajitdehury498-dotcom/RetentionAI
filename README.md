\# RetentionAI



AI-powered customer retention and churn prediction system.



\## Project Goals



\- Predict customer churn

\- Identify customers at high risk of leaving

\- Explain why customers are likely to churn

\- Generate personalized retention recommendations

\- Provide business-friendly insights



\## Technology



\- Python

\- Pandas

\- NumPy

\- Scikit-learn

\- Matplotlib

\- Seaborn

\- OpenPyXL



\## Project Structure



data/       - datasets

notebooks/  - experiments and analysis

src/        - reusable Python code

models/     - trained ML models

reports/    - analysis reports

tests/      - testing

app/        - application
